# Mi agenda

App web personal de tareas y calendario, pensada para instalarse en el iPhone desde Safari
(Compartir → Agregar a inicio), sin App Store.

- Funciona sin señal: guarda todo primero en el teléfono y sincroniza al volver la conexión.
- Dictado por voz en español o inglés.
- Los datos **no** están en este repositorio: viven en una hoja de Google privada del dueño,
  a la que la app llega a través de un pequeño servidor de Google Apps Script protegido con una clave.
  Este repositorio solo contiene la interfaz.

Archivos: `index.html` (la app), `sw.js` (copia para usar sin señal), íconos.
